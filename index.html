What is this?

Canvas Refined is a feature packed browser extension that upgrades your school's Canvas. It started as a fork of BetterCanvas — after it went in a direction we didn't like, Canvas Refined kept the good parts, fixed what was broken, and added a lot more. It works on both Chrome and Firefox.

Fully customizable dark mode
Automatic dark mode scheduling
Dashboard card color palettes
Custom backgrounds & daily backgrounds
A brand new, better todo list
GPA calculator (high school & college presets)
Better what-if grades
Grade analytics & history
Assignments due list
Dashboard notes with markdown
Global Canvas search (Ctrl/Cmd + K)
Gradient & advanced card customization
Custom fonts
Card styles (roundness, spacing, size & more)
Preview assignments & announcements from the dashboard
Browser-wide popup assignment reminders
Better sidebar
Quiz safe mode
Simplified UI that only shows what you need
...and more being added all the time!
